## What this proves

- The checked repository source is the same source identified by the Pi5 run hash.
- With this implementation, seed and parameters, source execution and deterministic-QBC execution produced identical histograms.
- All 200,000 observations were in the expected GHZ support set `{000, 111}`.
- The observed imbalance is small and consistent with ordinary sampling variation.
- The selected backend was explicitly CPU with no Vulkan attempt or fallback.

## What this does not prove

- No physical QPU was used: `physical_qpu=false`.
- It does not establish quantum advantage, quantum speedup or hardware quantum randomness.
- It does not prove that every branch or every language feature works.
- It does not convert the Raspberry Pi CPU/GPU into quantum hardware.

## Receipt limitation

The terminal output records valid JSON receipt paths and says the final package was ready, but the raw `source-run.json` and `qbc-exec.json` files were not imported into this GitHub update. Their unobserved contents are not reproduced or fabricated here.

For a stronger public evidence package, transfer those two receipt files, verify them with `jq -e .`, remove local paths or sensitive host metadata, and publish their SHA-256 values alongside the sanitized files.
